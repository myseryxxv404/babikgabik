## Описание программы
*"Random Task Generator (Генератор случайных задач) — это консольное приложение для ведения дневника погоды. Позволяет
добавлять записи о температуре, осадках, фильтровать их по дате и строить графики
температуры."*

- Библиотеки: `pip install matplotlib requests`
